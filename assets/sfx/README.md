# ASMR sound audition

The three approved ElevenLabs MP3s are now used by the runtime in `bakery-audio.js`. Enable Sound to load them and hear a preview. Butter uses cookie, cracker uses cracker, chocolate uses chocolate; sugar and jam use gentle cookie variations. The old noise-based synthesized food impacts have been replaced. The CC0 recording excerpts remain audition references only.

## ElevenLabs-generated food foley

`asmr-cookie.mp3`, `asmr-cracker.mp3`, and `asmr-chocolate.mp3` were generated using the configured ElevenLabs API key and the sound-effects endpoint. Each requested duration is 1.2 seconds. They are generated ASMR-style effects, not recordings of actual food. The API key was not saved in the project.

`elevenlabs-prompts.json` contains the prompts, model and duration settings. `asmr-comparison.wav` plays cookie, cracker, then chocolate, with silence between clips.
